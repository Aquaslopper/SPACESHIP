Sound effects for Spaceship Command
click.wav    Successful ordinary gameplay action
scan.wav     Scan starts
travel.wav   Crossing/jump starts
complete.wav Completed scan/arrival acknowledged
Replace files using the same names and standard 16-bit PCM WAV format
(mono/stereo, 8-192 kHz, max 32 MiB). Unsupported/missing files are silent.
These bundled effects are synthesized from this repository's reference game.
Music/effects toggles and volume are free controls on Home and Handbook.
