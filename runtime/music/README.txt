Music assets for Spaceship Command
ambient.wav loops after the first interaction when Music is on.
Replace it with your own 16-bit PCM WAV (mono/stereo, 8-192 kHz, max 32 MiB).
The bundled loop is synthesized from this repository's reference game.
No browser, JavaScript runtime, streaming or downloads are used by the EXE.
Missing/invalid audio or an unavailable audio device never blocks gameplay.
