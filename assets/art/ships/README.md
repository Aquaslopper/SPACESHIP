# Ship artwork

`wren-exterior.png` is a cropped, transparent-background adaptation of the Wren exterior concept supplied by the owner. The callout locations are illustrative UI anchors, not an asserted technical deck plan. The existing deck plan remains available in-game for the rooms and crew. No separate Kestrel exterior concept has been supplied; its existing diagram remains in use.

`cargo-spine-exterior.png` and `cargo-bulk-exterior.png` are the owner's selected AI-generated cargo hauler concepts, matched to the Wren illustration style. Their edge-connected paper backgrounds were removed for the same alpha-silhouette SDF extrusion, relief mesh, shader and orbit controls used by Wren. Both retain the installed room set and use the existing larger deck layout. The shipyard sells each for 1 shiplet. Cargo capacities (base / existing first refit / existing second refit) are 120 / 180 / 240 m3 for Spine and 240 / 360 / 480 m3 for Bulk, authored in `assets/data/ship.json`.
