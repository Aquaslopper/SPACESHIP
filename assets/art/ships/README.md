# Ship artwork

`wren-exterior.png` is a cropped, transparent-background adaptation of the Wren exterior concept supplied by the owner. The callout locations are illustrative UI anchors, not an asserted technical deck plan. The existing deck plan remains available in-game for the rooms and crew. No separate Kestrel exterior concept has been supplied; its existing diagram remains in use.

`cargo-spine-exterior.png` and `cargo-bulk-exterior.png` are the owner's selected AI-generated cargo hauler concepts, matched to the Wren illustration style. Their edge-connected paper backgrounds were removed for the same alpha-silhouette SDF extrusion, relief mesh, shader and orbit controls used by Wren. Both retain the installed room set and use the existing larger deck layout. The shipyard sells each for 1 shiplet. Cargo capacities (base / existing first refit / existing second refit) are 120 / 180 / 240 m3 for Spine and 240 / 360 / 480 m3 for Bulk, authored in `assets/data/ship.json`.

`explorer-needle-exterior.png` and `explorer-manta-exterior.png` are the owner's selected AI-generated **side-elevation** explorer concepts. Needle has a long tapered profile; Manta has a short rounded profile. The paper backgrounds were removed, and both use the same alpha-silhouette SDF/relief mesh and orbit rendering path as Wren and the cargo haulers. Each costs 1 shiplet at the shipyard. They use Wren's existing stats, six berths, compact room/deck layout and cargo-refit progression (20 / 60 / 90 m3 in a normal voyage; the existing reference-voyage fit retains its Wren base capacity). Only their displayed names, class labels and exterior art differ; no exploration bonuses or room types were added. The two cargo haulers remain available unchanged.

`yamato-exterior.png` and `arcadia-exterior.png` are the owner's selected AI-generated side-elevation interpretations of Space Battleship Yamato and Captain Harlock's Arcadia, rendered in the existing sepia illustration style. Their exterior paper backgrounds are transparent for the existing SDF/relief mesh and orbit renderer. Both are cosmetic Wren-stat variants: identical compact room layouts, six berths and Wren cargo/refit behavior, each sold for 1 shiplet. The illustrated turrets and other anime details do not add weapons, rooms, bonuses or gameplay systems. All previous ships remain available.
